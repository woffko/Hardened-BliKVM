# Feature and evidence matrix

`Runtime verified` means an authenticated read-only API reported the subsystem
online or enabled. It does not mean the BLi-KVM implementation exists or has
passed a physical interaction gate.

| Feature | Existing test baseline | BLi-KVM status | Required gate |
| --- | --- | --- | --- |
| HTTPS/login | Reachable; authenticated boundary verified | H616 TLS 1.2/1.3 Chromium setup/login, secure cookies, rotation, and logout passed | Certificate enrollment, other engines, and mobile matrix |
| Loopback server runtime | Not applicable | Unprivileged H616 server, systemd sandbox, Nginx loopback, and SSH-forward gates passed | Permanent packaging and reboot persistence |
| Read-only inventory | Five authenticated GET endpoints verified | Distinct-UID broker, dedicated-account rollback, `LoadCredential`, sanitizer, and repeated H616 inventory passed | Permanent least-privilege provisioning and reboot persistence |
| MJPEG | Streamer source online through authenticated API | Read-only Rust proxy/server path and TLS Chromium decode/reconnect passed on H616: 74 frames, 5 reconnects, 2 concurrent streams, session revocation, systemd isolation, and full rollback | Longer latency, hotplug, mode-switch, and soak matrix |
| Janus WebRTC | Disabled on current PiKVM baseline | Not advertised | Deliberate adapter decision and browser matrix |
| Keyboard | HID online through authenticated API | Fixed-route translator, 30-second session/target lease, fail-closed release, and crash ledger implemented but not wired | Safe target/focus, startup replay, 10,000-event, reconnect, and reboot test |
| Absolute/relative mouse | HID online; modes not physically exercised | Typed relative/absolute translation and release ledger implemented but not wired; Back/Forward rejected | Safe target/focus, mode, coordinate, scroll, button, reconnect, and reboot matrix |
| ATX/LED | Enabled, idle, power LED=true; pinned switch/LED offsets and existing KVMD ownership confirmed metadata-only | LED observation exposed read-only through sanitized inventory; all ATX actions remain unavailable and native takeover is blocked while KVMD owns lines | Persisted confirmation/idempotency/cooldown, explicit owner handoff, timing, electrical polarity, and physical gate |
| Virtual media | Enabled, online, idle, and disconnected through authenticated API | Read-only state advertised; opaque catalog, persisted policy, and fixed set-params/connect client implemented but not wired; mutating UI requires read_write | Catalog provisioning, disconnected no-op, safe attach/eject, upload, BIOS boot, interruption, reconnect, and reboot |
| SoC temperature | Fixed H616 sysfs source identified from vendor code | Bounded no-follow Rust inventory v2, runtime capability, 20-request systemd sandbox gate, and TLS Chromium Settings/About rendering passed on H616 | Controlled missing-sensor gate, longer observation, permanent packaging, and reboot persistence |
| External RTC | Kernel-bound `rtc-pcf8563 0-0051` and root-only `/dev/rtc1` observed read-only; clock is stale and not `hctosys` | Fixed no-follow sysfs reader, paired bounded inventory v3, 20-request systemd gate, runtime capability, and TLS Chromium Settings/About rendering passed; no clock write exists | Rebind/fault, drift/battery/reboot tests and a separately authorized clock-write policy |
| Fan/PWM | H616 chip0 offset 269 is a used legacy sysfs output with logical active-high metadata; physical polarity is unverified | Pure policy plus mock supervisor enforce startup, command-error, retry/latch and controlled-shutdown failsafe semantics; both are unlinked and capability remains unavailable | Exclusive legacy-owner handoff/rollback, physical pin/polarity/frequency/minimum-duty proof, crash/stall/fault injection, boot/restart and thermal soak |
| Display button/activity LED | Button offset257 is unused input; activity offset261 is a used legacy sysfs output; values were not read | Pure button one-shot and explicit-polarity LED schedule policies are host/codegen verified but unlinked; both capabilities hidden | GPIO input/output ownership, polarity/pull, physical bounce/press and visible LED timing, crash/reboot and display integration tests |
| Serial switch | No ttyUSB0-3 or serial/by-id directory in the current metadata-only H616 baseline | Pure no_std exact-frame codec is host/codegen verified but unlinked; capability hidden and no TTY opened | Deliberate hardware identity, exclusive 19200/8N1 ownership, bounded stream framing/timeouts, hotplug/reconnect and four-port physical tests |
| OLED/display | H616 vendor path maps ST7789 240x240 to root-only spidev1.0; source-associated GPIO259/260/262 are used legacy sysfs outputs | Metadata topology plus pure bounded window/rotation/RGB565 model are verified; model is unlinked and capability hidden | Exclusive SPI/GPIO handoff, initialization/electrical policy, worker timeouts, crash/reboot, burn-in/privacy and physical screen tests |
| Network inventory/config | NetworkManager active; sanitized sysfs baseline has active H616 Ethernet and inactive Wi-Fi drivers without addresses or identifiers | Metadata-only capture tool verified; no Rust adapter, Wi-Fi scan, address disclosure, or mutation capability | Typed eligible interfaces, secret-safe profiles, privilege separation, connectivity watchdog, commit/confirm rollback, out-of-band recovery and reboot matrix |
| System controls/logs | Vendor routes mix safe metrics with identity, raw logs and root shell reboot/hostname mutation | Actions lack a trusted floor; unlinked typed export/source/protocol/two-window policies accept no raw text/path/identity and make backpressure/incomplete EOF explicit | Different accepted floor hardware/firmware and action gates; SO_PEERCRED-bound diagnostic runtime, authenticated UI, and separate hostname work |
| Signed app update | Not established | Ed25519 verifier, immutable staging, anti-rollback journal, systemd credential confirmation, failed-candidate timeout, and restored-server rollback passed isolated H616 gates | Production key/channel policy, packaged installation, write interruption, and reboot matrix |
| Signed system update | Not established | Separate `sys-` trust domain, rootfs/boot verifier, and recovery geometry validator implemented; current live layout is explicitly rejected, with no writer or accepted profile | Complete recovery media, accepted exact H616 A/B profile, writer/readback, boot-control, reboot, and power-cut tests |
| Signed recovery image | Not established | Separate `recovery-` format plus canonical provenance/clearance validator and SPDX 3.0.1 binding implemented; no real passing input manifest or artifact exists | Cleared boot/rootfs inputs, accepted layout/key ceremony, byte-identical builds, two recovery cards, disposable-media and power-cut matrix |
| Automatic rollback | Not established | Application timeout rollback passed on H616; pure system dual-copy journal/selector reconciliation is host-tested but has no storage or boot adapter | Installed application watchdog, then accepted system selector/storage, interruption/reboot, A/B, and power-cut matrix |
